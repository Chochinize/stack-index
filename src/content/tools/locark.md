LocArk combines Markdown notes, password records and a quick-capture Inbox in a personal workspace stored in a location the user chooses. These core features are free; creating kanban boards and mind maps requires Pro. It is available on macOS, Windows, iPhone, iPad and Android.

New workspaces are locally encrypted with a master password; older unencrypted workspaces remain supported. Core features work offline. Users can choose a third-party sync folder, but LocArk does not provide hosted cloud sync. Pro activation or verification may require email and internet access.

**Portability boundary:** Native workspace records are in LocArk's own format, not a folder of ordinary Markdown files. A readable ZIP export provides notes centered on Markdown and converts password records, kanban boards, mind maps and Inbox content into readable text structures. This export is a portability copy, not a full-fidelity backup, and cannot be restored directly into LocArk. Readable exports can contain plaintext credentials and other sensitive data.

Website Pro options are US$4.90 per year with annual renewal or US$24.90 as a one-time lifetime purchase, with the same Pro features. Store pricing and terms may differ. See the [official pricing](https://locark.com/pricing/), [workspace setup and export guide](https://locark.com/locark-workspace-setup-guide/), and [import/export limitations](https://locark.com/locark-introduction/).
