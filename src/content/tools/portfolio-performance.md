Portfolio Performance calculates true time- and money-weighted returns across accounts, currencies, and asset classes, with detailed charts for allocation, performance, and net worth over time. Quotes update automatically, but every figure is computed on your own machine.

Because it's a local desktop app with no account, your complete financial picture never touches a fintech server — you just back up the data file.

**Good to know**
- True TTWROR / IRR performance calculations.
- Automatic quote updates for stocks, ETFs, and crypto.
- All data in a local file — nothing uploaded.
