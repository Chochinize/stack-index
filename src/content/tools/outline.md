Outline is a polished knowledge base for teams that you can run on your own infrastructure. It has a genuinely nice block-based Markdown editor, real-time collaboration, nested documents, and fast full-text search.

The source is available under the BSL, and the self-hosted deployment gives you a Notion-like docs experience where the content lives in your own database rather than a vendor's.

**Good to know**

- Docker Compose deployment; needs Postgres + Redis + object storage.
- SSO integrations (OIDC, Google, etc.) for teams.
- Source-available (BSL), not OSI-open-source — worth noting for licensing.
