linkding does one thing well: it stores your bookmarks, tags them, and makes them instantly searchable — all from a tiny self-hosted app that starts in seconds and sips resources.

It has a clean UI, a browser extension, bulk import from other services, and optional archiving of saved pages. If you've been meaning to escape a bookmarking service, this is the low-friction landing spot.

**Good to know**

- Single container; SQLite by default.
- Browser extension and a REST API.
- Optional snapshot archiving of saved links.
