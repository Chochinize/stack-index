Kaeso is an MIT-licensed, self-hosted AI gateway written in Rust. Apps call one OpenAI- or Anthropic-compatible API, and Kaeso applies SSO, budgets and request logs before forwarding requests to the providers you configure.

You run it on infrastructure you control, so those logs, budgets and access rules stay on your server rather than a hosted AI-gateway cloud.

**Good to know**

- OpenAI- and Anthropic-compatible APIs.
- SSO, budgets and request logs.
- MIT licensed; official install path is Docker Compose.
